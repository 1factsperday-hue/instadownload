# instadownload

A static preview for checking Instagram photo-post and Reel link formats.

## What it does

- Validates whether a submitted URL matches supported Instagram post/Reel URL patterns.
- Explains source-quality and access limitations in the interface.
- Uses a local illustrative image at `assets/media-preview.jpg`.

## Limitations

This is a **prototype only**. It does not connect to Instagram or Meta APIs, fetch post content, or download media. It does not scrape Instagram or bypass private/restricted content controls.

## GitHub Pages

The site is served from the repository root: `index.html` plus the local `assets/` directory. Once Pages is enabled for the `main` branch and `/` path, GitHub Pages publishes the static page at the repository's Pages URL.
